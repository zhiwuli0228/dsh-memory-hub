# dsh-memory-hub

DeepSeek Harness（DSH）的长期记忆中枢 —— **仓库初始化中（占位）**。

> 让 DSH 跨会话记住值得记住的事：可检索、可追溯、可干预。

## 当前状态

本仓库目前只有项目骨架：README、LICENSE、`.gitignore`、`.editorconfig` 和一个占位的 `package.json`。还没有可运行的代码，也尚未发布到 npm。设计讨论、接口草案与首个实现会在后续补充。

## 想解决的问题（草案）

- **跨会话记忆**：新会话能取回此前会话里的偏好、决定与结论，而不是从零开始。
- **写入有门槛**：什么值得记、记多久、何时遗忘都需要明确策略，避免把噪声写进长期记忆。
- **可检索**：按语义、关键词或时间检索，并给出每条记忆的来源（会话、事件、时间）。
- **可干预**：用户能查看、编辑、删除和导出记忆；默认本地存储，凭据不出本机。
- **与 DSH 集成**：作为插件运行，遵循 DSH 的插件与权限模型。

以上是待验证的方向，不是已经承诺的功能。
