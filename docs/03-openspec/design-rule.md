# Design Rule

设计文档必须回答以下问题。

## 必须包含

### 1. 目标与范围

- 解决什么问题
- 用户是谁
- 不做什么

### 2. 概念模型

- 涉及的实体
- 状态机
- 生命周期

### 3. 接口/API

- 新增/修改的 DSH 工具
- 面板路由
- 事件

### 4. 数据流

- 输入
- 处理
- 输出
- 持久化位置

### 5. 失败处理

- 降级策略
- 错误码
- 重试/幂等

### 6. 安全与边界

- 作用域影响
- 审批要求
- 路径/文件访问边界

### 7. 验证方式

- 测试用例
- 宿主冒烟步骤
- 面板验证步骤

## 设计文档位置

- 架构级设计：`docs/01-architecture/design.md` 或新 ADR。
- 功能级设计：`docs/03-openspec/designs/<feature>.md`。
- 更新后同步到 `docs/00-project/current-state.md`。
