# Spec Rule

规格说明应足够精确，可以直接指导实现。

## 必须包含

### 1. 接口签名

- 工具名
- 参数 schema（类型、必填、约束）
- 返回值 schema

### 2. 行为描述

- 正常流程
- 边界条件
- 错误分支

### 3. 持久化影响

- 读哪些文件
- 写哪些文件
- 是否产生 ledger 记录

### 4. 安全/审批要求

- 是否需要预检
- 是否需要审批
- 作用域校验

### 5. 示例

至少一个请求/响应示例。

## 禁止

- 使用“大概”、“可能”等模糊描述作为最终规格。
- 忽略失败分支。
- 省略 schema 约束。
